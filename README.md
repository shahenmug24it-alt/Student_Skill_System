# Student Skill Management System

A MERN Stack web application for managing student skills and learning progress.

## Technologies Used

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- API: REST API

## Features

- Student Login
- Mentor Login
- Student Management
- Skill Management
- Progress Management
- Add, View, Update and Delete skills
- Track student learning progress
